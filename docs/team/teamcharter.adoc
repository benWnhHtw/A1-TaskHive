== Zweck

*Was bauen wir, und warum?*

TaskHive ist eine kollaborative To-Do-Listen-Anwendung für Wohngemeinschaften, die die Organisation von Aufgaben und Verantwortlichkeiten im WG-Alltag neu strukturiert. Durch transparente Abläufe und eine faire, verlässliche Aufgabenverteilung wandelt die Anwendung alltägliche Pflichten wie Putzpläne oder gemeinsame Besorgungen in ein unkompliziertes System. Unser Ziel ist es, Verbindlichkeit zu schaffen, Missverständnisse zu reduzieren und das Zusammenleben in WGs durch klare Strukturen nachhaltig zu erleichtern

== Arbeitsweise

=== Definition of Ready (DoR)
_Eine User Story ist bereit für die Entwicklung, wenn:_

// Hier können die Kriterien individuell angepasst werden, z. B.:
* [ ] Die Akzeptanzkriterien sind klar und vollständig beschrieben
* [ ] Der Aufwand wurde vom Team geschätzt
* [ ] Abhängigkeiten sind identifiziert und geklärt
* [ ] Designs / Mockups sind vorhanden (falls relevant)

=== Definition of Done (DoD)
_Eine User Story gilt als fertig, wenn:_

// Hier können die Kriterien individuell angepasst werden, z. B.:
* [ ] Der Code wurde implementiert und in den Hauptbranch gemergt
* [ ] Code wurde erfolgreich getestet
* [ ] Der Code wurde von TechLead mindestens einer weiteren Person reviewt
* [ ] Die Funktionalität wurde im Staging-System getestet
* [ ] Dokumentation wurde aktualisiert (falls erforderlich)
* [ ] Der Product Owner hat die Story abgenommen
